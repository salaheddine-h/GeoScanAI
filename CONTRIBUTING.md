# Contributing to GeoScanAI

Thank you for helping shape GeoScanAI.

## Principles

- Keep changes scoped and intentional.
- Preserve the repository architecture unless a change explicitly requires evolution.
- Avoid adding application logic during foundation work.
- Document assumptions clearly.
- Prefer maintainable structure over premature implementation.

## Workflow

1. Discuss the change direction before large structural updates.
2. Keep pull requests focused on one concern.
3. Update documentation when the repository structure changes.
4. Validate that no unintended application code was introduced.

## Standards

- No business logic in scaffolding commits.
- No dependency installation unless explicitly approved.
- No API surface creation unless requested.
- No UI component implementation unless requested.
- Favor clarity, naming consistency, and long-term maintainability.
